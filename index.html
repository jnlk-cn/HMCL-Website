01 / ACCOUNTS

Verified ownership.
Your choice of skin service.

REQUIRED

Microsoft account

Before every game launch, HMCL authenticates the Microsoft account, checks the current Minecraft: Java Edition entitlement and retrieves the matching Minecraft profile from official services.

A cached profile or an earlier successful login does not replace those checks. Missing ownership, refused access, malformed responses or a network outage stop the launch.

OPTIONAL

Self-hosted skins

Yggdrasil-compatible services, including Blessing Skin, remain available for character and skin management. Select a skin-service character after adding your Microsoft account.

The skin-service character keeps its own UUID and session. It works with servers that explicitly trust that service. A skin-service account alone never enables gameplay.

  1. 1

    Add your Microsoft account

    Complete sign-in and consent directly on Microsoft's pages. The launcher never asks you to share a verification code with a maintainer.

  2. 2

    Choose your character

    Use the Microsoft profile, or add a trusted skin site's Yggdrasil API and sign in to its character.

  3. 3

    Launch through HMCL

    Ownership verification runs before the game process starts. A skin-service character also needs successful authentication at its own service.

Service availability

Microsoft and Mojang control API access for each application. A Microsoft consent page or device code does not establish Minecraft Services access. If the application's access is unavailable or denied, the game cannot launch through this distribution. Skin services do not bypass that restriction.

Official game sources

Minecraft manifests, game binaries, asset indexes and assets use Mojang's official HTTPS sources. There is no community mirror fallback for this content.

Third-party components

Loader and addon metadata can use BMCLAPI or MCIM alongside the original providers. Download mirrors are separate from account authentication.

Launcher-only packages

Releases include the launcher, its dependencies, corresponding source and SHA-256 checksums. No Minecraft game installation or personal account data is bundled.

Manual launcher updates

Launcher self-updates are disabled. Obtain a new launcher release manually. Game installation and game updates remain available when you request them.

Source and release artifacts are maintained in a private repository. Download links require repository access. This site publishes project information only.

03 / PRIVACY

Local account storage.
No usage telemetry.

Launcher usage telemetry and public-IP geolocation are disabled. Account sessions remain in local HMCL files; protect those files as private credentials. Optional saved skin-service passwords use Windows DPAPI and belong to the current Windows user.

Microsoft, Xbox and Minecraft account requests go to their official authentication endpoints. Skin-service credentials go only to the service you select. Microsoft tokens are not sent to a skin site or a download mirror.

Launch authorization is short-lived, single-use and kept in memory. Reusable game launch scripts containing account credentials are not exported. Local diagnostic logs omit authentication secrets; review logs before sharing them.

This static website uses no analytics, login forms or browser storage. GitHub Pages handles ordinary hosting requests under GitHub's privacy statement.
