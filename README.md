# HMCL project website

Static project information for the HMCL desktop distribution independently maintained by XDRi.Club.

Website: https://jnlk-cn.github.io/HMCL-Website/

Project contact: [minemacraft@outlook.com](mailto:minemacraft@outlook.com)

Downloads: https://jnlk-cn.github.io/HMCL-Website/#downloads

Current release: [HMCL 3.17.0.362](https://github.com/jnlk-cn/HMCL-Desktop/releases/tag/build/20261022-4bc238f). The website links directly to the Windows portable package, EXE, JAR, shell launcher, corresponding source and SHA-256 checksums. Downloading requires a GitHub account with access to the private launcher repository.

This public repository contains only the website. Launcher source and release artifacts remain in the private `jnlk-cn/HMCL-Desktop` repository. The site has no analytics, login forms or external script dependencies.
