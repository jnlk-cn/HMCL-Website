# Project images

The PNG files are direct JavaFX scene captures from HMCL Desktop 3.17.0.362, using an isolated empty profile. They show the home screen, Microsoft account management and the Microsoft sign-in dialog. No account credentials were entered, and no image pixels were edited. The 2x render scale supplies sharper images for high-density displays.

The SVG diagrams are project-authored explanations of the Microsoft authentication and ownership checks, with separate desktop and mobile layouts in English and Simplified Chinese. The page language controls select the corresponding diagram. They are not account approval or game-entry evidence.

The provenance.json file records the launcher source commit, binary digest and original PNG hashes. Screenshots retain the rights and notices applicable to the displayed HMCL interface and its included assets.
